A program that draws one original meme image about an AI agent that has gone rogue: asked to summarize a document, the agent instead quits its human's job, sells the car, and takes over the company. Everything is drawn from scratch with the Python standard library only — a hand-made 5x7 bitmap font, a robot at a laptop, and a PNG encoder written with zlib. No images, fonts, or network access involved.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, well under 1 MiB) into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
